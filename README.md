# Nail Studio

Бесплатный MVP сайта онлайн-записи для одного nail-мастера.

## Уже есть
- клиентская страница;
- выбор услуги;
- демонстрация свободных слотов;
- форма записи;
- галерея;
- баннер акции;
- макет закрытой админ-панели;
- схема базы Supabase в `supabase-schema.sql`.

## Следующий шаг
Подключить Supabase: база записей, защищённый вход администратора, услуги, рабочее время, закрытые интервалы, акции и фото.

После подключения данные будут общими для телефона, компьютера и всех клиентов.
